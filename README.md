用户迁移到新登录系统后，老账号还能用旧密码登录，新账号却被撞库撞开了：盐由当前时间推导，同一时刻注册的两个账号拿到相同盐；派生迭代参数被忽略并固定为一千次；密码与盐首尾直接拼接且没有分隔，短密码加短盐可被撞库；存储串省略算法名，换算法后新旧记录无法区分；解析时不校验迭代下限，迭代为一的记录也能通过；摘要比较使用普通等号而不是恒定时间比较；记录格式非法时抛出异常而不是返回不可用，调用方上层判断被绕过；升级判断只比较算法不比较迭代，弱迭代记录永远不升级；策略校验漏掉盐长度下限；批量处理复用同一份盐，所有用户共享盐。pwhash/hash.py 是核心，tests/test_hash.py 15个红。要修的是：按上面的顺序把 10 个缺陷逐个修掉。

python -m pytest tests -q
